# 坦克大战 · Tank Battle

一个使用原生 HTML5 Canvas + JavaScript 编写的经典《坦克大战》（Battle City）致敬小游戏，单文件、零依赖，可直接在浏览器中运行。

## 玩法

- **移动**：`W A S D` 或 方向键
- **射击**：空格键
- **暂停**：`P` 或 `Esc`
- **目标**：消灭每一关的全部敌方坦克，并保护屏幕下方的基地（旗帜）。基地被击毁或生命耗尽则游戏结束。

## 特性

- 经典地图元素：砖墙（可摧毁）、钢墙、河流、树林、基地旗帜
- 敌方坦克 AI：随机巡逻、追击玩家、自动开火
- 道具系统：火力升级 ★、护盾、加命、全场炸弹
- 关卡递增、最高分本地保存、护盾无敌与重生机制
- 即时音效（Web Audio）、粒子爆炸效果
- 单文件 `index.html`，无需构建工具

## 运行

直接双击 `index.html` 在浏览器中打开即可，或将本项目部署到 GitHub Pages：

1. 仓库 → Settings → Pages
2. Source 选择 `Deploy from a branch`，分支选择 `main`，目录 `/ (root)`
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问
